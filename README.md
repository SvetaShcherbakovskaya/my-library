# Домашнее задание № 40 — My Library

## React — электронная библиотека с фильтрацией по жанрам

Учебное приложение для просмотра книжного каталога. На одной странице отображаются общая статистика, полный список книг и отдельные разделы по жанрам.

**Тема:** функциональные компоненты, `props`, `children`, `map()`, `filter()`, `key` и условный рендеринг.

**Технологии:** React, Vite, JavaScript, JSX, CSS. Среда разработки — WebStorm.

## Цель задания

Разработать электронную библиотеку и закрепить передачу данных между компонентами, отображение и фильтрацию массивов, использование универсальных компонентов и условный рендеринг.

## Ограничения

- Не использовать `useState`, `useEffect`, Redux и другие механизмы управления состоянием.
- Не использовать обработчики событий, в том числе `onClick` и `onChange`.
- Выполнять фильтрацию через параметры компонентов, без интерактивного переключения жанров.
- Использовать единый исходный массив книг. Не создавать отдельные массивы для каждого жанра вручную.

## Исходные данные

В файле `src/data/books.js` хранится массив `books` из восьми книг, заданных в условии. Каждая книга содержит следующие поля:

| Поле | Описание |
| --- | --- |
| `id` | Уникальный идентификатор |
| `title` | Название |
| `author` | Автор |
| `year` | Год издания |
| `genre` | Жанр |
| `copies` | Количество доступных экземпляров |

## Основные требования

### Статистика библиотеки

В верхней части страницы необходимо показать:

```text
Всего книг в каталоге: 8
Доступны для выдачи: 6
```

Считается количество наименований, а не сумма физических экземпляров. Доступные наименования определяются с помощью `filter()` по условию `copies > 0`.

### Полный каталог

Отобразить все восемь книг с помощью `map()`. Для каждой книги использовать компонент `BookCard`, передавая объект книги через `props`. В качестве `key` использовать уникальный `id`.

Карточка должна содержать название, автора, год издания, жанр, количество доступных экземпляров, статус доступности и отметку для изданий до 2000 года.

### Разделы по жанрам

Ниже полного каталога разместить пять разделов:

1. Художественная литература.
2. Учебная литература.
3. Детская литература.
4. Публицистика.
5. Научно-популярная литература.

Для всех разделов использовать один компонент `BookList`. Фильтрация должна выполняться внутри него через `filter()` по значению пропса `genre`. Если жанр не передан, компонент должен показывать полный каталог.

В `App.jsx` создать массив `genres` и формировать разделы одним выражением `map()`, чтобы устранить повторяющуюся разметку. Для каждого раздела указать `key`.

### Условный рендеринг

- **Доступность:** при `copies > 0` показывать «Доступна», иначе — «Нет в наличии». Текст и CSS-класс выбирать тернарным оператором.
- **Классическое издание:** при `year < 2000` показывать «Классическое издание», используя `&&`.
- **Пустой результат:** если подходящих книг нет, с помощью `if` возвращать сообщение «В выбранной категории книги отсутствуют.».

### Универсальная карточка

Создать компонент `Card`, принимающий `children`. Он должен отвечать только за внешний контейнер и оформление, а содержимое получать от `BookCard`.

## Запуск проекта

В терминале из папки `my-library` выполнить:

```bash
npm install
npm run dev
```

Открыть в браузере адрес, который появится в терминале.

Для создания production-сборки:

```bash
npm run build
```

Для локального просмотра готовой сборки:

```bash
npm run preview
```

## Ожидаемый результат

Страница электронной библиотеки с восемью книгами в полном каталоге, статистикой и пятью разделами по жанрам. Данные передаются через `props`, содержимое универсальной карточки — через `children`. Списки формируются через `map()`, фильтрация выполняется через `filter()`, а статусы и дополнительные отметки выводятся с помощью условного рендеринга.
